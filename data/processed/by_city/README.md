# 陕西传统村落数据（按市拆分）

有数据的城市才生成独立 JSON/CSV 文件；没有数据的城市不生成文件，只在索引中显示 0。

## 文件

- `index.json`：全部城市索引，包含村落数量为 0 的城市
- `西安市.json` / `西安市.csv`
- `咸阳市.json` / `咸阳市.csv`
- `渭南市.json` / `渭南市.csv`
- `延安市.json` / `延安市.csv`
- `榆林市.json` / `榆林市.csv`
- `安康市.json` / `安康市.csv`

## 说明

- 数据来源：中国传统村落数字博物馆
- 采集时间：2026-11-11
- 当前共收录 37 个陕西村落
- 不代表陕西省完整传统村落名录
