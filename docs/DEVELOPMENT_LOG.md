# 开发过程记录（脱敏整理）

> 说明：本文档根据开发过程中的需求沟通整理，用于说明项目的迭代思路、设计取舍和问题解决过程。它不是原始聊天逐字记录，也不包含 API 密钥、账号密码、个人联系方式、无关争论或内部调试信息。

## 一、项目起点

项目面向 AI Web 网页开发挑战赛，主题确定为陕西传统村落数字档案。

最初确定的一级结构是：

- 首页
- 村落分布
- AI 问答

首页用于介绍传统村落及保护理念，村落分布用于按城市查找村落，AI 问答用于基于村落资料进行交流。

## 二、需求迭代摘录

以下内容为沟通过程中的关键需求摘要，已经过脱敏和归纳。

> “村落分布不要县级标签，点击城市后直接展示该市的传统村落。”

因此数据结构采用“城市 → 村落”的两级关系，不单独设置县级标签。

> “村落的各个标签可能不相同，有的村落有传统文化，有的没有。”

因此没有采用固定模板硬编码全部标签，而是根据已整理数据动态生成历史文化、环境格局、传统建筑、民俗文化、美食物产、村志族谱和旅游导览等模块。没有资料的模块不显示。

> “AI 先从村落数据中检索答案，如果现有资料没有，再去网上找正规资料，不能瞎编。”

因此 AI 问答增加了本地档案检索、来源编号、正规网页白名单和资料不足提示。

> “普通交流也要能识别，不只是你好。”

因此 AI 增加了意图分流：

- 问候、自我介绍、感谢和告别使用固定自然回复
- 普通聊天使用 `deepseek-chat`
- 村落知识问题使用本地档案检索和 `deepseek-reasoner`
- 连续追问会结合上一轮对话识别正在讨论的村落

> “API 不能显示在后端里，因为后端也要提交。”

因此密钥只通过服务器环境变量 `DEEPSEEK_API_KEY` 注入，不写入源码、前端、数据库、截图或公开仓库。

> “图片怎么上传，反馈接口怎么处理？”

因此增加了后台上传、图片压缩、WebP 转换、反馈校验、蜜罐、限流和重复提交检查。

## 三、页面与视觉迭代

### 首页

首页经历了以下调整：

- 使用陕西传统村落真实照片作为全屏背景
- 三张背景轮流切换，保留暂停和指示点
- 增加陕西传统村落数据概览
- 增加精选村落、今日一村和保护古村内容
- 增加水墨线描、印章和艺术字，但避免装饰遮挡正文
- 背景切换不使用大面积黑色遮罩
- 页面底部保留流动墨线动画
- 清理重复照片，保证首页背景与其他图片区块不重复

### 村落分布

- 左侧介绍陕西传统村落的分布特点
- 右侧按陕北、关中、陕南组织城市
- 城市纵向排列，没有村落的城市显示为 0
- 增加陕西地图和城市节点
- 增加背景图片轮换和中国风线描装饰
- 手机端修复横向溢出

### 村落详情

- 顶部使用村落照片轮换
- 二级标签根据村庄资料动态生成
- 正文使用可滚动文字框，避免长文把页面撑得过高
- 图片统一尺寸，并保持文字与图片的布局平衡
- 修复图片加载、文字乱码和重复图片问题
- 移除无效的图片点击放大功能，降低加载负担

## 四、AI 问答迭代

AI 模块最终形成以下链路：

1. 识别普通交流、问候、身份询问和村落知识问题
2. 从已发布村落的档案章节中检索相关内容
3. 将检索结果作为上下文交给 DeepSeek
4. 要求模型只能引用后端提供的资料编号
5. 本地资料不足时，检索政府、官方媒体和传统村落官网
6. 白名单过滤所有网页域名
7. 没有可靠来源时明确提示资料不足
8. 模型服务不可用时退回本地档案摘录

使用的模型：

- `deepseek-reasoner`：村落知识问题和深度思考
- `deepseek-chat`：普通交流

来源白名单包括：

```text
gov.cn
dmctv.cn
ncha.gov.cn
mct.gov.cn
xinhuanet.com
people.com.cn
shaanxi.gov.cn
whhlyt.shaanxi.gov.cn
cnwest.com
```

## 五、后台管理迭代

后台从基础 CRUD 逐步补充为完整内容管理：

- 管理员登录和登录会话
- 城市管理
- 村落管理
- 内容模块管理
- 历史人物和历史环境要素管理
- 媒体管理
- 图片上传和删除
- 意见反馈处理和状态流转
- 整理数据导入

图片上传规则：

- 支持 JPG、PNG、WebP
- 默认限制 8MB
- 自动去除 EXIF
- 最长边压缩到 2600px
- 统一转为 WebP
- 数据库只保存访问地址
- 删除记录时同步删除本地文件

## 六、问题与解决

### 背景图片显示不稳定

问题：页面初次加载或切换时出现灰色区域。

处理：使用预加载、图片加载状态判断和本地资源，避免依赖不稳定的远程图片。

### 页面在手机上横向溢出

问题：装饰图超出屏幕宽度。

处理：增加横向裁切规则，并在 390px、768px 和桌面尺寸下检查所有页面。

### AI 只有固定演示回复

问题：初始版本只有前端模拟。

处理：增加真实的 `/api/ai/chat` 接口、村落档案检索、DeepSeek 调用和来源返回。

### 普通交流被误判为村落问题

问题：没有资料时所有内容都返回“资料不足”。

处理：增加普通交流识别和 `deepseek-chat` 对话模式。

### API 密钥泄露风险

处理：密钥只存在服务器环境变量，公开仓库只保留 `backend/.env.example` 空配置；同时清除数据库会话和测试反馈。

### 重复图片

处理：统一检查首页背景、保护古村、精选村落和轮播图片，替换重复素材，保留独立图片。
